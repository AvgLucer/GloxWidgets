Open the extracted folder and launch the included Glox Library application.

### 4. Add Your Games

Inside Glox Library:

```text
+ ADD GAME
      ↓
Game Name
      ↓
Game Cover
      ↓
Game .EXE
      ↓

      ↓
SAVE
```

Your game will then appear inside your personal library.

### 5. Play

Click the game card and select **PLAY**.

Glox Library launches the configured executable directly.

## Why Use Glox Library?

Glox Library is designed for games that don't necessarily belong to a major storefront.

You don't need to:

* Add the game to Steam
* Add the game to Epic Games
* Depend on a desktop shortcut
* Use another launcher
* Reconfigure the game every time

Instead, Glox Library stores the executable path and game configuration locally.

> **Add it once. Save it once. Play it whenever you want.**
