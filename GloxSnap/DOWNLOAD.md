## 🖥️ Supported Capture Modes

### Full Screen

Captures the entire primary display.

### Region

Allows you to manually select a rectangular area of the screen.

While selecting, GLOX SNAP displays the dimensions of the selected region.

Press **ESC** to cancel.

### Window

Attempts to capture the currently focused application window.

## 📂 Screenshot Location

By default, screenshots are stored in:

```text
Pictures/
└── GLOX Screenshots/
```

Screenshots are saved using the format:

```text
GLOX_Snap_YYYYMMDD_HHMMSS.png
```

You can change the destination folder from:

```text
Right Click → Screenshot Folder...
```
