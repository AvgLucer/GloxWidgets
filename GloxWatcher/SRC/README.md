## 📁 About

This directory contains the source code and Python dependencies for **GloxWatcher**, a premium floating desktop **Timer + Stopwatch** utility developed under **Glox Industries**.

The source is provided for developers who want to inspect, run, modify, or build upon GloxWatcher.

---

## 📦 Contents

| File               | Description                  |
| ------------------ | ---------------------------- |
| `gloxwatcher.py`   | Main GloxWatcher application |
| `requirements.txt` | Required Python packages     |

---

## ⚙️ Requirements

* **Python 3.x**
* **PySide6**
* Windows desktop environment

All required Python packages are listed in:

```text
requirements.txt
```

---

## 🚀 Setup

Clone or download the repository, then navigate into the `SRC` directory:

```bash
cd SRC
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run GloxWatcher

Launch the application with:

```bash
python gloxwatcher.py
```

---

## 🛠️ Development

The main application is contained in a single Python file:

```text
gloxwatcher.py
```

The application uses **PySide6 / Qt** for its desktop interface and handles the timer, stopwatch, alarms, themes, opacity, and floating-window functionality within the application.

Developers are free to inspect the source and experiment with modifications for personal or educational purposes.

---

## ✨ Core Components

* Countdown Timer
* Stopwatch
* Lap functionality
* Timer presets
* Custom countdown duration
* Alarm sounds
* Multiple visual themes
* Adjustable window opacity
* Always-on-top floating window
* Frameless desktop interface
* Draggable widget
* PySide6-based UI
