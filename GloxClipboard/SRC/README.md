# Glox Clipboard — Source Code

> **Source code for Glox Clipboard by Glox Industries.**

This folder contains the source implementation of **Glox Clipboard**, a lightweight desktop clipboard-history widget.

---

## 📁 Source Structure

```text
SRC/
│
├── gloxclipboard.py
├── requirements.txt
└── README.md
```

### `gloxclipboard.py`

The main Glox Clipboard application.

It handles the clipboard-history functionality, widget interface, themes, opacity customization, item pinning, and item removal.

---

## ✨ Features

The source version includes:

* 📋 Clipboard history
* 📌 Pin clipboard items
* 🗑️ Remove clipboard items
* 🎨 Multiple themes
* 🪟 Adjustable widget opacity
* 💎 Glassmorphism-inspired interface
* ⚡ Lightweight desktop widget
* 🔄 Automatic clipboard monitoring

---

## 🛠️ Requirements

Make sure **Python 3.10+** is installed.

Install the required dependencies with:

```bash
pip install -r requirements.txt
```

---

## ▶️ Running From Source

From inside the `SRC` directory:

```bash
python gloxclipboard.py
```

The Glox Clipboard widget should launch on your desktop.

---

## 📦 Dependencies

The project's Python dependencies are listed in:

```text
requirements.txt
```

It is recommended to use a virtual environment when developing or modifying the project.

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Then install the dependencies:

```bash
pip install -r requirements.txt
```
