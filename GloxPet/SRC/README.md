## 🐾 About

**GLOX PET** is a lightweight animated robotic desktop companion built entirely with **Python + PySide6**.

It lives on your desktop, reacts to clicks, walks around, blinks, sleeps, changes themes, talks through speech bubbles, performs animations, and can even launch a full-screen fireworks celebration.

No external image assets are required — the pet is rendered procedurally using **Qt QPainter**.

## 🖱️ Interactive Controls

| Action              | Reaction                            |
| ------------------- | ----------------------------------- |
| 🖱️ **1 Click**     | Happy animation + random message    |
| 🖱️ **2 Clicks**    | 360° cartwheel                      |
| 🖱️ **3+ Clicks**   | Celebration + full-screen fireworks |
| 🖱️ **Left Drag**   | Move the pet                        |
| 🖱️ **Right Click** | Open control menu                   |

> **One click is an answer. Two clicks is 360°. Three clicks is fireworks.**

## 🔥 Fireworks System

Triple-clicking the pet triggers a procedural celebration featuring:

* 🚀 Animated rockets
* 💥 Particle explosions
* ✨ 70-particle bursts
* 🎇 Diwali-style fountains
* 🌌 Full-screen transparent overlay
* ⚡ Real-time particle physics

The entire effect is generated dynamically without requiring pre-rendered assets.
