# GloxAud — Source Code

Welcome to the **GloxAud source code**.

This folder contains the source files used to build and develop **GloxAud**, a lightweight microphone privacy and control utility from **Glox Industries**.

## 📁 Contents

The `SRC` folder contains the development/source files required for working on GloxAud.

```text
SRC/
├── gloxaud.py
└── README.md
```

> The exact files may vary depending on the current development version.

## 🛠️ Requirements

* Python 3.x
* Required Python packages listed in the source code or project documentation
* Windows recommended for full functionality

Install dependencies with:

```bash
pip install -r requirements.txt
```

if a `requirements.txt` file is included.

## ▶️ Running From Source

Navigate to the `SRC` directory and run:

```bash
python gloxaud.py
```

If the main source filename differs, replace `gloxaud.py` with the appropriate entry-point file.

## 🧩 Development

The source version is intended for:

* Development
* Debugging
* Customization
* Learning
* Contributing
* Building your own executable

The packaged `.exe` is recommended for users who simply want to run GloxAud without setting up the development environment.

If you want to create a standalone Windows executable, use the project's build instructions or your preferred Python packaging tool.
