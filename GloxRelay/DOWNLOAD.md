## 📦 Installation

</div>

Glox Relay is designed as a lightweight Python desktop application.

### Step 1 — Download

Download:

**GloxRelay.zip**

### Step 2 — Extract

Extract the ZIP file to a location of your choice.

### Step 3 — Install Requirements

Open a terminal inside the extracted folder and run:

```bash
pip install -r requirements.txt
```

### Step 4 — Launch

Run:

```bash
python gloxrelay.py
```
