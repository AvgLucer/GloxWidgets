# 📂 About

This folder contains the **GloxMusic source code**.

GloxMusic is a lightweight desktop music player built around local music playback, customization, and a premium PySide6 interface.

> **Your Music • Your Space**

---

# ⚙️ Requirements

Before running or modifying the source code:

### **Check `requirements.txt` first.**

It contains the dependencies required by the current version of GloxMusic.

Install them with:

```bash
pip install -r requirements.txt
```

### Core Technologies

| Technology    | Purpose           |
| ------------- | ----------------- |
| Python        | Application logic |
| PySide6       | GUI               |
| Qt            | UI framework      |
| Qt Multimedia | Audio playback    |

> Always use the dependency versions specified in `requirements.txt` when available.

---

# 🚀 Running From Source

From the project directory:

```bash
pip install -r requirements.txt
```

Then run the appropriate GloxMusic Python entry point:

```bash
python gloxmusic.py
```

If the source structure changes between versions, **use the current files and configuration provided in the repository** rather than assuming the example command above is unchanged.
