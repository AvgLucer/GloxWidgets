## 📂 About This Folder

This folder contains the **source code for Glox Celebrate**.

Glox Celebrate is a lightweight desktop celebration utility that allows users to customize their celebration experience through different modes, adjustable duration, and adjustable intensity.

This directory is intended for users who want to:

* 🔍 Study the source code
* 🧑‍💻 Learn from the implementation
* 🛠️ Modify the project
* 🧪 Experiment with the application
* 📚 Understand how the project works

## ▶️ Running From Source

Navigate to the `SRC` directory:

```bash
cd SRC
```

Then run:

```bash
python gloxcelebrate.py
```

If your system uses `python3`:

```bash
python3 gloxcelebrate.py
```

## ⚙️ Glox Celebrate

The application provides controls for:

### ⏱️ Duration

Choose how long the celebration should continue.

### 🔥 Intensity

Adjust the intensity of the celebration effects.

### 🎊 Celebration Modes

Select from the available celebration modes to change the visual celebration experience.
