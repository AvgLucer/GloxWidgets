## 🐍 Running From Source

If you prefer running Glox QR directly from Python, make sure you have:

* Python **3.10+**
* PySide6
* The required QR-generation dependencies

Clone or download the repository, install the required packages, and run the main Python file.

```bash
pip install -r requirements.txt
```

Then:

```bash
python gloxqr.py
```

> The exact filename may vary depending on the current project version.

## 🛠️ Troubleshooting

### ❌ Application doesn't start

Try extracting the ZIP completely before launching the application.

Do **not** attempt to run the application directly from inside the compressed ZIP archive.

### ❌ Windows blocks the application

Windows Defender or SmartScreen may display a warning for applications that are not widely distributed or digitally signed.

Only proceed if the package was downloaded from the official Glox QR release link.

### ❌ Source version shows a missing module

Install the project's dependencies:

```bash
pip install -r requirements.txt
```

If the issue persists, make sure you are using **Python 3.10 or newer**.
