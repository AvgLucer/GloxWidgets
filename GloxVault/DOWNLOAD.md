# 🔐 About GloxVault

GloxVault is designed to provide a simple way to keep selected files protected inside a dedicated vault.

Files added to the vault are encrypted and stored using the `.glox` extension.

The vault is designed to work especially well with removable storage such as:

* USB Flash Drives
* Pendrives
* External SSDs
* External HDDs
* Local Storage

# 💾 Portable Storage

GloxVault can be stored on a USB drive or other removable storage.

Example:

```text
USB Drive
│
└── GloxVault
    │
    ├── GloxVault.exe
    │
    └── Vault
        │
        ├── b10389aosldmba02945.glox
        ├── x82kq91mzla02918.glox
        └── p91xmd73kaq10482.glox
```

This allows the vault and protected `.glox` files to remain together on portable storage.

# 🔒 Security Concept

GloxVault is designed so that files stored inside the vault are not kept in their normal readable form.

The general workflow is:

```text
Original File
      ↓
   GloxVault
      ↓
   Encryption
      ↓
Protected .glox File
      ↓
   GloxVault
      ↓
    Extract
      ↓
Original File
```

The `.glox` file is intended to be accessed through GloxVault rather than treated as the original file.
